*pinwords*  Pin words you want to keep in your head.

==============================================================================
PINWORDS                                                      *pinwords.nvim*

Pin words to keep them visible while reading or reviewing code.

REQUIREMENTS
  - Neovim >= 0.12

HEALTH                                                          *pinwords-health*

  Run `:checkhealth pinwords` to validate current config values and
  optional picker dependencies.

SETUP                                                           *pinwords-setup*
>lua
  require("pinwords").setup({
    slots = 9,
    whole_word = true,
    case_sensitive = false,
    auto_allocation = {
      strategy = "first_empty", -- "first_empty" | "cycle" | "lru"
      on_full = "replace_oldest", -- "replace_oldest" | "replace_last" | "no_op"
      toggle_same = true,
    },
    flash = {
      enabled = true,
      timeout_ms = 120,
      hl_group = "PinWordFlash",
      priority = 250,
    },
    -- Custom highlight colors (see |pinwords-colors|)
    colors = nil,
    -- Optional picker integrations (see |pinwords-pickers|)
    telescope = {
      enabled = false,
    },
    snacks = {
      enabled = false,
    },
    fzf_lua = {
      enabled = false,
    },
  })
<

PERSISTENCE                                                *pinwords-persistence*

  Highlights remain until you clear them (they do not disappear automatically).
  Pins are global across all buffers and are not saved across Neovim sessions.

AUTO ALLOCATION                                          *pinwords-auto-allocation*

  strategy:
    first_empty  Use the lowest available slot.
    cycle        Rotate slots sequentially; uses 'on_full' when full.
    lru          Replace least-recently used when full.

  on_full:
    replace_oldest  Replace the oldest pinned slot.
    replace_last    Replace the most recently pinned slot.
    no_op           Do nothing when full.

  toggle_same:
    true   If the same raw text with the same match semantics exists,
           unpin it (toggle off).
    false  Always allocate a new slot (or replace based on policy).

  Notes ~
    - 'on_full' is used only with strategy=first_empty/cycle.
    - With strategy=lru, a slot is always selected; 'on_full' is ignored.

FLASH FEEDBACK                                          *pinwords-flash-feedback*

  A short visual flash is shown on successful pin/unpin operations.

  enabled:
    true   Enable visual feedback.
    false  Disable visual feedback.

  timeout_ms:
    Flash duration in milliseconds. 0 clears on the next event loop tick.

  hl_group:
    Highlight group used for flash (default: PinWordFlash).

  priority:
    Match priority for flash highlighting.

COMMANDS                                                       *pinwords-commands*

  :PinWord              Auto pin (toggle same). Visual range pins selection.
  :PinWord {slot}        Pin word under cursor (visual range pins selection).
  :PinWordSymbol         Pin symbol at cursor using Treesitter (auto allocation).
  :PinWordSymbol {slot}  Pin symbol at cursor to specific slot.
                         Falls back to cword when no parser or no symbol found.
  :UnpinWord             Unpin word under cursor.
                         Warns when multiple slots share the same raw text.
  :UnpinWord {slot}      Clear slot.
  :UnpinAllWords         Clear all pinned words.
  :PinWordList           Interactive picker for global pinned words.
  :PinWordCwordToggle    Toggle cursor-word highlight (current window, incl. insert).
  :PinWordNext [slot]    Jump to next pinned word occurrence.
  :PinWordPrev [slot]    Jump to previous pinned word occurrence.
  :PinWordGrep [slot]    Grep pinned words across project.
  :PinWordLiveGrep [slot] Live grep pinned words across project.

API                                                             *pinwords-api*

  setup({opts})                                              *pinwords.setup()*
    Initialize pinwords with optional configuration.
    Parameters: ~
      {opts}  (PinwordsConfig|nil) Configuration table.

  set({slot}, {opts})                                          *pinwords.set()*
    Pin a word to a slot. If slot is nil, auto-allocate.
    When called without opts.raw, uses word under cursor.
    Parameters: ~
      {slot}  (integer|nil) Slot number (1-N). nil for auto allocation.
      {opts}  (table|nil)   Options table:
                raw           (string|nil)  Explicit text to pin.
                whole_word    (boolean|nil) Match whole words only. Word
                              boundaries are applied only at ends that are
                              keyword characters, so `-foo` still matches.
                case_sensitive (boolean|nil) Case-sensitive matching.
                source        ("cword"|"symbol"|nil) Use Treesitter symbol.

  toggle({opts})                                            *pinwords.toggle()*
    Toggle pin for word under cursor (alias for set with auto allocation).
    Parameters: ~
      {opts}  (table|nil) Same options as set().

  cword_toggle()                                      *pinwords.cword_toggle()*
    Toggle cursor-word highlight for the current window.

  unpin()                                                   *pinwords.unpin()*
    Unpin the word under cursor if it is currently pinned.

  clear({slot})                                              *pinwords.clear()*
    Clear the pinned word in the given slot.
    Parameters: ~
      {slot}  (integer) Slot number to clear.

  clear_all()                                            *pinwords.clear_all()*
    Clear all pinned words from every slot.

  list()                                                     *pinwords.list()*
    Return a deep copy of all currently pinned slots. Mutating the returned
    table does not affect plugin state.
    Returns: ~
      table<integer, PinwordsSlot>

  get_config()                                          *pinwords.get_config()*
    Return a deep copy of the current configuration.
    Returns: ~
      PinwordsConfig

  pick()                                                     *pinwords.pick()*
    Open interactive picker for pinned words.
    Tries enabled pickers in order: snacks -> telescope -> fzf_lua ->
    vim.ui.select.

  jump_next({slot})                                      *pinwords.jump_next()*
    Jump to the next occurrence of a pinned word.
    Parameters: ~
      {slot}  (integer|nil) Slot to restrict search, or nil for all slots.
    Returns: ~
      boolean  true if a match was found.

  jump_prev({slot})                                      *pinwords.jump_prev()*
    Jump to the previous occurrence of a pinned word.
    Parameters: ~
      {slot}  (integer|nil) Slot to restrict search, or nil for all slots.
    Returns: ~
      boolean  true if a match was found.

  grep({opts})                                              *pinwords.grep()*
    Grep pinned words across the project.
    All pinned words are combined with OR into a single search pattern, while
    each slot keeps its own whole_word/case_sensitive behavior. Uses the best
    available picker backend.
    Parameters: ~
      {opts}  (table|nil)   Options table:
                slot  (integer|nil) Specific slot to grep, or nil for all.

  live_grep({opts})                                    *pinwords.live_grep()*
    Live grep pinned words across the project.
    Opens an interactive live grep with pinned words as the initial query.
    Parameters: ~
      {opts}  (table|nil)   Options table:
                slot  (integer|nil) Specific slot to grep, or nil for all.

CUSTOM COLORS                                                  *pinwords-colors*

  Customize highlight colors per slot:
>lua
  require("pinwords").setup({
    colors = {
      [1] = "#ff6b6b",                           -- hex string
      [2] = { bg = "#1dd1a1", fg = "#000000" },  -- with foreground color
      [3] = { bg = "#54a0ff", bold = true },     -- with style attributes
      [4] = { sp = "#ff6b6b", undercurl = true }, -- colored undercurl (no background)
      cword = "#ffd166",                         -- cursor word color
    },
  })
<
  Color specification formats: ~
    "#ff6b6b"                  Hex string (background color only)
    { bg = "#ff6b6b" }         Table with background color
    { bg = "#ff6b6b", fg = "#000000" }  With foreground color
    { bg = "#ff6b6b", bold = true }     With style attributes
    { sp = "#ff6b6b", undercurl = true }  Colored undercurl (no background)

  Available style attributes: ~
    bg           Background color (hex string)
    fg           Foreground color (hex string)
    sp           Special color for underline/undercurl (hex string)
    bold         Bold text
    italic       Italic text
    underline    Underlined text
    undercurl    Curly underline
    underdouble  Double underline
    underdotted  Dotted underline
    underdashed  Dashed underline
    strikethrough  Strikethrough text
    ctermbg      Terminal background color (integer 0-255; estimated from
                 bg if omitted)
    ctermfg      Terminal foreground color (integer 0-255; estimated from
                 fg if omitted)

JUMP NAVIGATION                                                *pinwords-jump*

  Jump between pinned word occurrences:
>lua
  -- Recommended key mappings
  vim.keymap.set("n", "]p", function() require("pinwords").jump_next() end)
  vim.keymap.set("n", "[p", function() require("pinwords").jump_prev() end)

  -- Jump to specific slot (optional)
  vim.keymap.set("n", "]1", function() require("pinwords").jump_next(1) end)
  vim.keymap.set("n", "[1", function() require("pinwords").jump_prev(1) end)
<
  Behavior: ~
    - Wraps at file boundaries (end -> beginning, beginning -> end)
    - Supports count prefix (e.g., 3]p jumps 3 times)
    - Integrates with jumplist (<C-o> to return)

HIGHLIGHTS                                                     *pinwords-highlights*

  PinWord1 .. PinWord9
  PinWordCword
  PinWordFlash

  Groups you define yourself (e.g. via |nvim_set_hl()|) are preserved. Groups
  defined by the plugin are refreshed whenever |pinwords.setup()| is called
  again or the colorscheme changes.

GREP INTEGRATION                                              *pinwords-grep*

  Search your entire project using pinned words. All pinned words are combined
  with OR into a single search pattern, while each slot keeps its own
  whole_word/case_sensitive behavior.

  Commands: ~
    :PinWordGrep            Grep all pinned words (OR combined).
    :PinWordGrep {slot}     Grep a specific slot's word only.
    :PinWordLiveGrep        Open live grep with pinned words as initial query.
    :PinWordLiveGrep {slot} Open live grep with a specific slot's word.

  Picker Backend: ~
    Grep uses the same priority as other picker features:
    snacks -> telescope -> fzf-lua -> quickfix fallback.
    Grep backends are line-oriented, so multi-line pinned words are skipped.
    When no picker backend is available, both commands fall back to a quickfix
    grep. The fallback prefers asynchronous tools so the UI stays responsive:
    rg when available, then git grep inside a Git repository, and finally a
    synchronous vimgrep only when neither is present.

  Example Key Mappings: ~
>lua
    vim.keymap.set("n", "<leader>pg", function()
      require("pinwords").grep()
    end, { desc = "Grep pinned words" })
    vim.keymap.set("n", "<leader>pl", function()
      require("pinwords").live_grep()
    end, { desc = "Live grep pinned words" })
<

PICKER INTEGRATIONS                                        *pinwords-pickers*

  pinwords.nvim provides optional integrations with popular picker plugins for
  browsing and managing pinned words through a fuzzy finder interface.

  All picker integrations are completely optional - pinwords.nvim works
  perfectly without them. When no picker is enabled, :PinWordList uses
  vim.ui.select as a built-in fallback.

  Common Features: ~
    - List all pinned words with slot number and highlight color
    - Fuzzy search by slot number or word text
    - Multi-select to unpin multiple words at once
    - Unpin individual words or clear all

  Common Key Mappings: ~
    <Tab> / <S-Tab>   Toggle multi-selection
    <CR> / <Enter>    Unpin selected word(s) - supports multi-select
    <C-d>             Unpin current word
    <C-x>             Clear all pinned words
    <Esc> / <C-c>     Close picker

TELESCOPE.NVIM                                            *pinwords-telescope*

  Telescope.nvim extension for pinwords.

  Setup (optional auto-loading): ~
>
    require("pinwords").setup({
      telescope = {
        enabled = true,
      },
    })
<
  Usage: ~
    :Telescope pinwords

    require("telescope").extensions.pinwords.pinwords({opts})

SNACKS.NVIM                                               *pinwords-snacks*

  Snacks.nvim picker integration for pinwords.

  Setup (optional auto-loading): ~
>
    require("pinwords").setup({
      snacks = {
        enabled = true,
      },
    })
<
  Usage: ~
    require("pinwords.snacks").picker({opts})

  Note: To keep multi-select stable in Snacks, pinwords assigns a unique `id`
  to each entry.
